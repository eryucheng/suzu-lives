# Suzu Lives 使用说明

这份说明书按当前软件里的实际入口编写。它回答两件事：某项东西是做什么的，以及要从哪里开始。页面上实际显示的状态、按钮和错误信息优先于说明书；软件更新后，说明书也会随软件更新。

## 先完成四件事

第一次使用时，按下面顺序即可开始聊天：

1. 打开 **设置 → 主模型**，选择模型服务，填写服务商提供的地址、模型标识和 API Key，然后保存。
2. 打开 **对话**，点联系人栏右上角的 **+**，填写备注并创建联系人。
3. 打开 **关系 → 相处设定**，选择该联系人，在 **SUZU.md** 写下人设、关系、说话方式和希望长期遵循的规则。可用 `@文件名.md` 把同一目录里的资料分开引用。
4. 回到 **对话** 开始聊天。普通文字聊天不需要先安装其他能力。

主模型是联系人聊天和“问 Suzu”共同使用的文本模型。图像、视频、语音等能力用的 API 连接则单独保存在 **设置 → API**，再由各项能力按名称选用；不要把两类配置混在一起。

## 想做什么，去哪里

| 想做的事 | 从这里开始 |
| --- | --- |
| 和某位联系人聊天，改备注、头像、聊天显示、审批模式、主动关心或长期记忆开关 | **对话 → 选中联系人 → ··· → 设置** |
| 写人设、关系、背景和长期相处规则 | **关系 → 相处设定** |
| 查看或维护长期记忆、上下文整理、Agent 日记 | **关系** |
| 配置图像、视频、语音、微信、日记、网页等可选功能 | **能力** |
| 让软件在未来某个时间向联系人发起一轮对话，或运行本机脚本 | **计划** |
| 记录纪念日、生日和其他重要日期 | **今天** |
| 整理参考图、生成和比较图片 | **创造 → 视觉工作台** |
| 修改自己的资料，或查看费用和调用量 | **管理** |
| 配置主模型、API、外观、数据位置和隐私 | **设置** |

## 顶部的“问 Suzu”

按 `Ctrl + K` 或点击顶部输入框，会打开一段独立的“问 Suzu”对话。它是软件使用助手，可以：

- 说明某项功能的用途、前置条件和操作步骤；
- 帮你打开对应页面；
- 直接切换浅色或深色主题；
- 当说明书不能解释或页面状态与说明不一致时，检查本机的软件配置、诊断记录和已安装的软件文件，再依据实际结果回答。

“问 Suzu”维护独立的对话记录。你明确要求排查某位联系人时，它会将该联系人的本机资料作为参考；API Key、密码和令牌始终保持私密。

目前“问 Suzu”可直接执行**打开页面**和**切换主题**。涉及联系人、API、能力、资料或文件的改动，它会说明步骤、带你到对应位置，并依据实际结果说明完成情况。

## 今天：日期、日记和当日概览

**今天** 是首页，用来查看日历、联系人的重要日期、Agent 日记入口、最近调用和今日成本。

- 在日历中选择日期后点 **添加日期**，选择联系人，填写名称、日期和分类。可设为每年重复，也可暂时不显示在日历中而保留记录。
- 日历里的“联系人日期”和节日用于提醒与查看资料；需要到点执行的事项，请到 **计划** 新建计划。
- “日记”卡片会打开 **关系 → 查看日记**。
- “今日成本”和“最近活动”卡片都会打开 **管理 → 用量与成本**。在用量页可分别看近 14 天的按日柱状图和近 12 个月的按月柱状图；零调用的日期或月份也会保留，便于比较。

## 对话：联系人与当前会话

**对话** 是每位联系人的固定聊天窗口。一个联系人有自己的聊天记录、相处资料、记忆、附件、权限设置和已启用能力。

- 联系人列表顶部可按备注搜索；用右侧 **+** 新建联系人。
- 选中联系人后，右上角 **··· → 设置** 可以修改备注和头像，展开“聊天显示”调整显示内容，选择时间显示方式，并设置这位联系人的审批模式。
- 审批模式只作用于当前联系人：默认是 **全权限**；需要收紧本机操作范围时，可改为 **工作目录可写** 或 **只读**。已有聊天、资料和记忆都会保留。
- **主动关心** 的开关在这里。打开后，Suzu 会在软件运行期间结合你们的对话安排后续联系；关闭后会停止为这位联系人创建新的主动关心任务。
- **长期记忆** 的开关也在这里。关闭后会停止自动写入和召回；已有记忆仍可在 **关系 → 记忆** 中查看、检索和维护。
- 发送第一条消息后，设置面板会出现 **本地附件**；可点“打开文件目录”定位这位联系人的图片和文件。若已开启微信总开关，这里也会出现该联系人的 **微信连接**。
- 输入框可发送普通文字、表情、图片和文件。点击文件按钮选择附件；把图片直接粘贴到输入框，会先成为待发送附件，再由你确认发送。
- Agent 的 Markdown 回复会按标题、列表、表格、链接和代码等形式显示。聊天中的图片会显示预览；右键文件卡片可**复制**文件，或用**打开**在资源管理器中定位它。
- 正在处理时，直接发送新消息会把当前回复拉向新要求；若想等当前回复结束后再处理，输入 `/suzu queue 内容` 排队。输入 `/suzu stop` 或使用停止操作可终止当前一轮；停止后会保留已有历史。
- 对联系人点右键可置顶、标为未读、开启免打扰、隐藏或删除。**隐藏**会将她移出对话列表，可在 **设置 → 隐私** 恢复；**删除**会清理该联系人的聊天、附件、记忆、自动任务和关联软件数据。文件关联无法安全核对时，软件会保留相关数据并提示确认。

## 关系：相处资料、记忆、日记与上下文整理

**关系** 集中管理这段关系长期留下的内容。进入后有四张卡片：

- **相处设定**：编辑该联系人的 Markdown 资料，包括 **SUZU.md**、`persona.md`、`user.md` 和你新增的资料文件。SUZU.md 适合写名字、身份、关系、表达方式、边界和长期规则；其他资料可按主题拆开，再用 `@背景.md`、`@偏好.md` 这类引用组织。保存后从下一轮聊天开始生效，已有聊天记录保持原样。
- **记忆**：查看、检索、测试召回和维护长期记忆。这里适合核对某条长期信息是否正确；联系人设置里的“长期记忆”开关控制自动写入和召回，已有记录可在这里继续维护。
- **记忆压缩器**：整理模型当前可见的较早聊天内容，并保留聊天界面和原始会话记录。
- **查看日记**：按联系人浏览 Agent 在每天设定时间写下的回顾。日记独立于聊天、长期记忆和上下文整理。

### 三种“记住”的东西有什么不同

- **长期记忆**：从聊天里留下、并在相关新一轮按需召回的信息。适合稳定的事实、偏好和关系状态。
- **Agent 日记**：每天的一篇回顾。先到 **能力 → 行动 → 写日记** 为联系人开启和设定时间，再到 **关系 → 查看日记** 或首页“日记”卡片浏览。日记在软件运行时按设定时间写入。
- **上下文整理**：把较早聊天总结成模型继续对话所需的摘要，同时保留近期原话；聊天界面和原始会话记录完整保留。

### 上下文整理（记忆压缩器）

在 **关系 → 记忆压缩器** 中，可按联系人设置聊天上下文的整理方式。

- 自动整理的目标值是上下文约到 **32,000 Token** 时整理，并保留最近约 **8,000 Token** 的原话；两个数值都可按联系人调整。模型可用输入空间较小时，软件会同步缩小这两个值，避免超出该模型的窗口。
- 模型接近其可用输入上限时会启动一次保底整理，保持聊天连续。
- “立即压缩”会整理较早消息，并保留你指定数量的最新原话。
- 每位联系人都可改自己的摘要提示词。清空后保存会恢复软件内置默认提示词。

## 计划：让软件到点做事

**计划** 管理本机保存的定时任务。新增计划时依次选择：

1. **类型**：一次性（若干小时、分钟后触发）或每天（指定时间）。
2. **主体**：联系人或系统。
3. 联系人计划填写提示词；到点后软件把它投递到选定联系人的会话。系统计划选择一个 `.cmd`、`.bat` 或 `.py` 脚本；脚本会在它自己的目录中运行。

已保存的计划可以单独开启、关闭或删除。**计划历史**保留最近 100 次已触发记录，方便查看它是否已投递、完成、失败或中断。系统计划需要所选脚本文件存在且可运行。

## 创造：当前是视觉工作台

**创造** 提供 **视觉工作台**，用于把提示词、参考资料和候选结果放在同一处推进一次视觉创作。

- 写下画面方向，选择参考资料，再生成和比较候选图片。
- 从本机导入参考图时，可选择保存到“我的共享资料”或“当前联系人的专属资料”。专属资料按联系人保存。
- **图像生成** 和 **手机拍照式图像** 是否可用取决于是否已配置对应能力。先在 **设置 → API** 新建连接，再到 **能力 → 创作** 绑定并为联系人启用。
- 语音、音色和语音通话不在创造页配置，请到 **能力 → 创作 → 语音消息**。

## 能力：为联系人接入额外功能

**能力** 是可选功能的配置中心。它分为四类：**感知**（图片、视频、时间）、**陪伴**（日常互动、联系方式）、**行动**（工具、日记等）和**创作**（图片、声音、视觉资料）。

人设在“关系 → 相处设定”，长期记忆和主动关心的开关在当前联系人的聊天设置。大多数能力需要先选 API，再按联系人范围启用：

1. 到 **设置 → API** 新建 API 连接。填写唯一备注、服务地址、密钥和服务商要求的字段。
2. 到 **能力**，在对应分类中打开能力详情。
3. 在详情中选择刚才的 API 备注，并填写模型名、音色 ID 等服务商专有参数。
4. 在“联系人范围”选择哪些联系人可以使用它。

API 连接的备注不能重复。删除一条 API 连接后，引用它的能力会回到未选择状态，需要重新绑定其他连接。

### 外部能力（Skill / MCP）

如果已有本地 Skill 或 MCP 能力，可到 **能力 → 外部能力** 导入它的 `suzu-capability.json`。

1. 导入阶段会读取这份本地清单并显示静态检查结果。
2. 检查无误后，对需要的能力点“启用并登记”。Skill 会登记到 Suzu 管理的技能目录，MCP 会作为 Agent Core 的工具连接。
3. 需要停用或删除时，回到同一页操作。若软件发现相关受管文件被手动改过，会保留文件并提示确认。

### 图像理解与视频理解

- **图像理解**：先在 **设置 → API** 新建支持图像输入的连接，再到 **能力 → 感知 → 图像理解** 选择连接、调整读取偏好并为联系人启用。之后在聊天中发送图片并提出问题。
- **视频理解**：路径是 **能力 → 感知 → 视频理解**。选择支持视频输入的连接、为联系人启用后，发送完整视频并说明想了解什么。视频会作为视频输入交给所选模型理解。

### 时间感知

在 **能力 → 感知 → 时间感知** 中为联系人启用并设置间隔，默认是 10 分钟。同一会话超过该间隔后，下一轮会得到新的本机日期、星期和当前时间。时间信息会作为该轮的动态上下文参与模型请求，回复结束后从活动上下文移出；聊天界面仅显示实际消息。

### 语音消息与语音通话

1. 在 **设置 → API** 分别新建文字转语音（TTS）和语音识别（ASR）所需连接。
2. 到 **能力 → 创作 → 语音消息**，选择对应连接，填写模型名和音色 ID，并为联系人启用。
3. 语音通话还需要选择 ASR 连接，并按需要调整通话灵敏度。

配置并启用 ASR 后，聊天输入框的麦克风可录入一段语音；识别结果会先写进输入框，确认后才发送，仍可像普通文字一样修改。

### 图像生成与手机拍照式图像

在 **能力 → 创作** 打开对应能力，选择图片服务连接或本机 ComfyUI 设置，再为联系人启用。需要参考图时，到 **创造 → 视觉工作台** 整理资料。

### 写日记、邮箱、微信与网页自动化

- **写日记**：到 **能力 → 行动 → 写日记** 为联系人启用并设置每日时间；浏览入口在 **关系 → 查看日记** 或首页“日记”。
- **邮箱通道**：在能力详情填写 SMTP / IMAP 所需信息，再选择联系人范围。
- **微信**：先到 **能力 → 陪伴 → 连接微信** 打开总开关，并选择投递内容。默认投递 Agent 的最终回复和审批提示；可在能力详情调整投递范围。之后到指定联系人的 **对话 → ··· → 设置 → 微信连接** 生成二维码，扫码后从该微信号发送一条文字消息确认绑定。一个二维码对应创建它的联系人固定会话；等待回复时，微信会显示“对方正在输入…”。
- **网页自动化**：如能力页已开放，在详情启动 Suzu 专用浏览器并登录网站。登录状态保存在本机专用 profile；联系人只能在已启用范围内使用它。

## 管理：我的资料与费用

**管理** 有两个页面：

- **我**：修改聊天中显示的自己的名称、头像和签名。
- **用量与成本**：查看本机已记录的调用流水、会话费用、模型价格以及按日、按月费用趋势。若服务商返回的模型名称没有内置价格，可新建价格映射，用于软件中的费用估算显示。

## 设置：软件全局配置

**设置** 管理整个软件的全局配置。

### 常规

- **软件更新**：查看公告、检查、下载并安装已发布的版本；开发构建或不支持更新的安装方式会明确显示状态。
- **首次引导**：如果此前选择了“稍后设置”，可从这里重新完成主模型、联系人和人设配置。
- **外观**：选择浅色或深色，也可以直接对“问 Suzu”说“切换深色模式”。

### 主模型

这里设置联系人聊天和“问 Suzu”使用的文本模型。选择服务商或兼容协议，填写 Base URL、模型标识和 API Key，保存后再开始新的对话。若服务商支持读取模型列表，可在此页刷新；拿不准字段时请以服务商文档为准。

### API

这里保存可复用的能力 API 连接。每条连接有一个唯一备注；新建后可在相应能力详情中按备注选择。

### 数据

- **数据存储位置**：设置、API 连接、联系人资料、Agent 工作数据、生成内容和本地缓存都保存在这里，与软件安装目录分开。
- 更换位置后，旧位置会作为安全副本保留。确认新位置可用后，可回到这里点“清理旧副本”。
- **系统状态检查**：提供对 Suzu 数据、联系人工作区和本机 Agent Core 结构的只读检查。

### 隐私

这里可以查看并恢复隐藏联系人。隐藏会将联系人移出对话列表，并保留消息、记忆、主动关心和其他资料。

## 遇到问题时

1. 先确认当前页面是否显示“已配置”“已启用”或明确错误信息。
2. 对模型、图像、视频、语音类问题，确认 API 连接、模型名、音色 ID 与联系人范围是否都已完成。
3. 对数据或会话问题，到 **设置 → 数据 → 系统状态检查** 查看本机受管文件是否有异常。
4. 仍无法判断时，直接问“问 Suzu”。它会先读本说明书，再在你要求时检查本机实际配置、诊断记录和软件文件，并说明实际查到的结果。
