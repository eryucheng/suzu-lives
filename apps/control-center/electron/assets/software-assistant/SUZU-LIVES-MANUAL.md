# Suzu Lives 使用说明

这份说明书面向正在使用 Suzu Lives 的人。它说明每个已开放入口是做什么的、通常需要先准备什么，以及完成一件事应从哪里开始。页面实际显示的选项和状态始终优先于本说明书；软件更新后，说明书也会随软件一起更新。

## 先完成四件事

第一次使用时，按下面顺序即可开始聊天：

1. 打开 **设置 → 主模型**，选择模型服务，填写服务商提供的地址、模型标识和 API Key，然后保存。
2. 打开 **对话**，点联系人栏右上角的 **+**，填写一个备注并创建联系人。
3. 打开 **关系 → 相处设定**，选择该联系人，在 **SUZU.md** 写下人设、关系、说话方式和希望长期遵循的规则。可用 `@文件名.md` 把同一目录里的资料分开引用。
4. 回到 **对话** 开始聊天。需要的能力可稍后单独配置，不影响普通文字聊天。

主模型是联系人聊天和“问 Suzu”共同使用的文本模型。能力 API 则在单独的 API 连接库里保存，再由各能力按名称选用；不要把两类配置混在一起。

## 顶部的“问 Suzu”

顶部输入框不是普通搜索。它是软件使用助手，可以：

- 说明某项功能的用途、前置条件和操作步骤；
- 帮你跳到对应页面；
- 直接切换浅色或深色主题；
- 当说明书不能解释或页面状态与说明不一致时，检查本机的软件配置、诊断记录和已安装的软件文件，再依据实际结果回答。

它不是某位联系人，默认不会自动把联系人聊天、人设、相处资料或长期记忆带入自己的对话；只有你明确要求它排查某位联系人的本机资料时，它才会查阅。它也不会在对话中索取或复述 API Key、密码和令牌。

## 今天

**今天** 用来查看日期、日历事件、重要日期、近期活动和今日成本。

- 要添加或修改一个日期：在日历中选择日期后点新增或编辑，填写标题、日期和需要的说明。
- 重要日期、节日和计划中的时间信息会在这里集中查看。
- 这里的“今日成本”是本机已记录的调用费用摘要；完整流水在 **管理 → 用量与成本**。

## 对话与联系人

**对话** 是每位联系人的固定聊天窗口。

- 新建联系人：点联系人列表右上角 **+**，备注只在 Suzu 中显示；同名备注也可以存在。
- 改备注、头像、显示方式或本地附件位置：打开当前聊天的更多设置。
- 普通文字、图片和文件都通过当前联系人的固定会话发送。图片、音频和文件会保存在本机数据目录中。
- 聊天界面保留原始消息；上下文整理只影响模型下一轮看到的内容，不会把聊天记录从界面删掉。
- 要临时停止一轮正在回复的内容，使用聊天页的停止操作；不要把停止当作删除历史。

## 关系与相处设定

**关系** 用来管理联系人本身；**相处设定** 用来写这位联系人的资料。

- **SUZU.md** 是该联系人的主设定文件，适合写名字、身份、关系、表达方式、边界和长期规则。
- 可以新建其他 Markdown 资料，例如 `背景.md`、`偏好.md`，再在 SUZU.md 中用 `@背景.md`、`@偏好.md` 引用。这样能把不同主题分开整理。
- 修改资料后，下一轮聊天会按新的资料组装上下文；它不会自动改写已有聊天记录。
- 删除联系人会清理属于该联系人的聊天、附件、能力配置和软件数据。删除前请确认，因为这不是“隐藏”。
- 如果只是暂时不想在聊天列表看到某人，到 **设置 → 隐私** 隐藏或恢复联系人；隐藏不会删除她的资料。

### 长期记忆、日记与上下文整理的区别

- **长期记忆**：从聊天中保存并在相关新一轮召回的信息。可在联系人设置关闭；关闭后已有记忆仍保留，但不会自动写入或召回。
- **查看日记**：Agent 按每日设置写下当天回顾，独立于聊天和长期记忆。
- **上下文整理**：把较早的聊天内容总结为模型可继续使用的摘要，同时保留最近若干条原始内容。它不会从聊天界面删除历史。

## 计划

**计划** 管理本机保存的定时任务、每日任务和脚本。

- 新增计划时，先明确要执行的内容、时间或触发规则，以及它面向哪位联系人。
- 可在计划历史查看已运行的结果和失败信息。
- 若选择本机脚本，请先确认脚本本身存在且能在自己的目录运行；软件不会把不存在的脚本变成可执行任务。

## 创造

**创造** 是图片工作台、视觉参考和声音设计的入口。

- **视觉工作台**：写下画面方向，选择参考资料，再生成和比较候选图片。
- **视觉参考资料**：导入本机图片后，选择它是“我的共享资料”还是“当前联系人的专属资料”。专属资料不会出现在其他联系人中。
- **图像生成** 和 **手机拍照式图像** 是否可用取决于是否已配置对应能力。先在 **设置 → API** 新建连接，再到 **能力 → 创作** 绑定并为联系人启用。

## 能力：通用配置方法

能力是可按联系人启用的功能，不是安装后自动对所有联系人生效。大多数需要模型服务的能力都按下面步骤配置：

1. 到 **设置 → API** 新建 API 连接。填写唯一备注、服务地址、密钥和服务商要求的字段。
2. 到 **能力**，在对应分类中打开能力详情。
3. 在能力详情选择刚才的 API 备注；模型名、音色 ID 等服务商专有参数也在这里填写。
4. 在“联系人范围”选择哪些联系人可以使用它。
5. 回到该联系人的聊天中使用。若能力页显示未配置、未启用或暂未接入，以页面状态为准。

API 连接的备注不能重复。删除一条 API 连接后，引用它的能力会回到未选择状态，需要重新绑定其他连接。

### 图像理解

用途：让联系人理解用户明确发送的一张图片。

1. 在 **设置 → API** 新建支持图像输入的连接。
2. 到 **能力 → 感知 → 图像理解** 选择该连接，按需要调整图片读取细节和超时。
3. 在联系人范围中启用。
4. 在聊天中发送图片并提出问题。

### 视频理解

用途：让联系人理解用户明确提供的一段完整视频。

1. 在 **设置 → API** 新建支持视频输入的连接。
2. 到 **能力 → 感知 → 视频理解** 选择连接并设置读取密度等偏好。
3. 为需要的联系人启用。
4. 发送视频并说明想了解什么。

视频会作为完整视频输入交给所选模型；Suzu 不会用本机抽帧来假装完成视频理解。

### 时间感知

用途：在聊天间隔较长后，让联系人在下一轮知道本机日期、星期和当前时间。

1. 到 **能力 → 感知 → 时间感知**。
2. 为联系人启用，并设置间隔；默认是 10 分钟。
3. 同一会话超过该间隔后，下一轮会得到新的时间信息。

时间信息只为当轮服务，会在该轮完成后从活动上下文移除，不会变成聊天气泡。

### 语音消息与语音通话

用途：让联系人发送语音，或用于实时语音通话。

1. 在 **设置 → API** 分别新建文字转语音（TTS）和语音识别（ASR）所需连接。
2. 到 **能力 → 创作 → 语音消息**，选择对应连接。
3. 填写服务商提供的模型名和音色 ID；没有音色时可先新增音色，再为联系人选择。
4. 为需要的联系人启用。语音通话还需要选择 ASR 连接，并按需要调整通话灵敏度。

### 图像生成与手机拍照式图像

用途：生成、编辑图片，或让画面具有后置、自拍、镜前等手机拍摄感。

1. 在 **设置 → API** 新建图片服务连接；如果使用本机 ComfyUI，则在能力详情填写本机 ComfyUI 设置。
2. 到 **能力 → 创作** 打开对应能力，选择出图方式和连接。
3. 为联系人启用；需要参考图时先在 **创造 → 视觉工作台** 整理资料。

### 写日记与主动关心

- **写日记**：到 **能力 → 行动 → 写日记** 为联系人启用并设置每日时间。软件运行到设定时间后，Agent 会写当天第一篇回顾；软件未运行的日期不会补写。
- **主动关心**：到 **能力 → 陪伴 → 主动关心** 为联系人开启，并按需要修改触发提示词。它只在软件运行时维护任务。

### 邮箱通道、微信和网页自动化

这些功能是否出现、能否启用，以 **能力** 页及其详情状态为准。

- **邮箱通道**：先在能力详情填写 SMTP / IMAP 所需信息，再选择联系人范围。
- **微信**：在指定联系人的聊天设置中生成二维码，扫码后从该微信号发送一条文字消息确认绑定。每个二维码只连接创建它的联系人固定会话。
- **网页自动化**：如能力页已开放，先在详情启动 Suzu 专用浏览器并登录网站；登录状态保存于本机专用 profile。之后联系人可在已启用范围内使用该浏览器处理网页。

## 管理

**管理** 包含“我”和“用量与成本”。

- **我**：修改聊天中显示的自己的名称、头像和签名。
- **用量与成本**：查看本机记录的调用流水、会话费用和模型价格。若服务商返回的模型名称没有内置价格，可以新增价格映射；这只影响费用计算显示，不会修改服务商实际收费。

## 设置

### 常规

- **软件更新**：查看公告、检查、下载并安装已发布的版本；开发构建或不支持更新的安装方式会明确显示状态。
- **外观**：选择浅色或深色。也可以直接对“问 Suzu”说“切换深色模式”。

### 主模型

这里设置联系人聊天和“问 Suzu”使用的文本模型。

选择服务商或兼容协议，填写 Base URL、模型标识和 API Key，保存后再开始新的对话。若服务商支持读取模型列表，可在此页刷新；拿不准字段时请以服务商文档为准。

### API

这里保存能力复用的 API 连接。每条连接有一个唯一备注。创建后不会自动让任何能力使用它，仍需去能力详情按备注选择。

### 数据

- **数据存储位置**：设置、API 连接、Agent 数据、生成内容和本地缓存都保存在这里。更换位置会保留旧位置的安全副本，确认新位置可用后才清理旧副本。
- **系统状态检查**：只读检查 Suzu 数据、联系人工作区和本机 Agent Core 的结构，不会修改文件。

### 隐私

可以查看并恢复隐藏联系人。隐藏只从对话列表移除，不会删除消息、记忆、主动关心或其他资料。

## 遇到问题时

1. 先确认当前页面是否显示“已配置”“已启用”或明确错误信息。
2. 对模型、图像、视频、语音类问题，先确认 API 连接、模型名、音色 ID 与联系人范围是否都已完成。
3. 到 **设置 → 数据 → 系统状态检查** 查看本机受管文件是否有异常。
4. 仍无法判断时，直接问“问 Suzu”。它可以先读本说明书，再检查本机实际配置、诊断记录和软件文件；它会说明自己实际查到了什么，而不是编造结果。
