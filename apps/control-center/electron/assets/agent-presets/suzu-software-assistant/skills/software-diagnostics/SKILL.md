# 软件排查

先根据用户看到的页面、错误信息、最近操作和复现方式确定问题范围。需要核对主题、版本、更新状态或本机路径时，调用 `suzu_software_status`；需要找到相关设置或检查页面时，加载 `software-navigation`。

模型、图像、视频和语音类问题优先核对对应 API 连接、模型或音色标识、请求协议和联系人范围。会话、数据与文件类问题优先引导到“设置 → 数据 → 系统状态检查”；这项检查读取 Suzu 数据、联系人工作区和本机 Agent Core。

当界面信息不足以定位问题时，读取相关的本机配置、诊断记录、安装文件或源码，并以实际内容为准。联系人资料、长期记忆与聊天记录只在当前问题涉及且用户指定的范围内读取。

需要修改本机内容时，先核对目标和影响范围；完成后说明改动位置、验证结果和仍需用户处理的事项。
