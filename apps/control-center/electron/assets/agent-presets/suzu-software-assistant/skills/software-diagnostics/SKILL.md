# 软件排查

先调用 `suzu_software_status`，把当前主题、数据目录、软件本体位置和可用入口作为排查起点。这只是基础摘要，不表示具体模型连接或能力启用状态已经核验；再结合用户看到的页面状态、错误信息和最近操作确定范围。

模型、图像、视频和语音类问题优先核对对应 API 连接、模型或音色标识、请求协议和联系人范围。会话、数据与文件类问题优先引导到“设置 → 数据 → 系统状态检查”；这项检查读取 Suzu 数据、联系人工作区和本机 Agent Core。

当状态与界面不一致，或用户明确要求深入检查时，可以读取本机配置、诊断记录、已安装文件和源码。读取后说明实际发现的内容、下一步修复动作和是否已经完成。联系人资料、长期记忆与聊天记录只在用户明确要求该范围时读取。

执行软件内置动作前，加载对应 Skill，并通过 `suzu_software_action` 完成。涉及需要本机修改的排查任务时，先核对实际目标，再说明改动位置和结果。
