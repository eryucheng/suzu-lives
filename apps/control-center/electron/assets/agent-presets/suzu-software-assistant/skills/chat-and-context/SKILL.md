# 聊天与上下文

联系人聊天位于“对话”。输入框支持文字、表情、图片和文件；粘贴图片会先成为待发送附件，确认后进入会话。图片在对话中显示预览，文件卡片可复制或在资源管理器中打开所在位置。

正在处理时，直接发送新消息会把本轮回复转向新的要求。`/suzu queue 内容` 会把内容排到当前回复之后，`/suzu stop` 用于停止当前一轮。停止后的已完成内容和原始记录仍会保留。

“关系”页用于查看和维护三类长期内容：

- **长期记忆**保存适合在后续相关对话中召回的稳定信息。
- **Agent 日记**显示 Agent 已写下的每日回顾。写入时间在“能力 → 行动 → 写日记”统一设置，并按联系人启用；软件未运行的日期不会补写。
- **记忆压缩器**整理较早会话上下文，并保留近期原话与完整聊天记录。

联系人会话会按已启用能力把时间、节日和相关记忆等背景加入当轮模型请求。软件触发的自动任务以系统任务上下文进入当前轮次。需要核对这些内容时，读取对应的计划记录或目标联系人的配置。

上下文整理的默认目标约为 32,000 Token，并保留约 8,000 Token 的近期原话。当前模型的可用上下文较小时，软件会同步缩小触发量和保留量，保证整理仍能执行。联系人可以在“关系 → 记忆压缩器”中调整整理方式、保留量和摘要提示词，也可以立即压缩。
