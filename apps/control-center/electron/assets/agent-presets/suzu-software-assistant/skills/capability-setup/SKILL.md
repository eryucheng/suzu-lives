# 能力配置

先确认用户想让哪位联系人完成什么事，再确定所需的 API、协议、模型和联系人范围。通常先在“设置 → API”保存可复用连接，再到“能力”选择连接、请求协议、适配器和模型参数，并为目标联系人启用能力。不同联系人可以使用不同的能力组合。

常见入口如下：

- 图像理解与视频理解在“能力 → 感知”。主模型本身支持视觉时，聊天图片会直接交给主模型；需要保底识图时，再配置图像理解。视频理解将完整视频交给所选视频模型。
- 语音消息在“能力 → 创作 → 语音消息”。先选择请求协议和 API，再建立语音适配器、音色，并为联系人分配音色。语音通话另行选择 ASR 连接。
- 图像生成在“能力 → 创作 → 图像生成”。请求协议、API 连接和默认模型在此配置；手机拍照式画面和视觉工作台复用这套配置。
- 写日记、计划和网页自动化位于“能力 → 行动”。邮箱通道位于“能力 → 陪伴”。主动关心在“计划”和当前联系人设置中统一管理。
- 微信与 QQ 的机器人或通道配置位于“能力 → 陪伴”，具体联系人绑定在该联系人的对话设置中完成。

内置协议覆盖常用服务；服务尚未内置时，可在详情的“请求协议”区域新建自定义协议，保存后再选择它建立适配器。自定义协议填写服务地址、请求路径、Headers、请求 JSON 与结果解析规则；页面会显示可用变量。

本地 Skill 或 MCP 通过“能力 → 外部能力”导入 `suzu-capability.json`，检查后再启用并登记。启用完成后，Skill/MCP 会登记到 Suzu 管理的全局 Agent Core，供所有联系人共享。

围绕用户要达成的结果说明需要的 API、协议、模型与联系人范围；涉及外部 Skill/MCP 时，说明其全局共享范围。需要打开相关页面时，加载 `software-navigation`。
