# 管理与设置

“管理 → 我”用于修改自己的显示名、头像、性别和个性签名。“管理 → 用量与成本”显示调用流水、会话费用、模型价格以及按日和按月的趋势；服务商模型没有内置价格时，可以新建价格映射用于费用估算。

“设置 → 数据”管理数据存储位置和系统状态检查。设置、API、联系人资料、Agent 工作数据、生成内容与本地缓存都跟随数据目录。隐藏联系人在“设置 → 隐私”恢复。

软件更新、首次引导和外观位于“设置 → 常规”。主模型在“设置 → 主模型”，可复用 API 连接在“设置 → API”；它们分别由 `model-and-api-setup` 说明。

先根据用户目标确定页面和要保存的信息。需要跳转或切换主题时，加载 `software-navigation` 并使用已登记的软件动作。
