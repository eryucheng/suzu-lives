# DeepSeek

## 主模型

- 工具厂商 ID：`deepseek`
- 官方 OpenAI 兼容地址：`https://api.deepseek.com`
- Suzu 默认模型：`deepseek-v4-flash`
- Suzu 已登记模型：`deepseek-v4-flash`、`deepseek-v4-pro`、`deepseek-v4-flash-vision-exp`
- 用户只提供 DeepSeek API Key 且用途是主模型时，可直接保存；模型选择沿用用户指定值或 Suzu 默认值。

## 独立 API 连接

- 工具厂商 ID：`deepseek`
- Suzu API 连接预设地址：`https://api.deepseek.com/v1`
- 连接类型：`openai-compatible`
- 默认模型按用途选择。普通文本可用 `deepseek-v4-flash`；需要图片输入时使用厂商当前支持视觉输入的模型，并核对能力适配器支持情况。
