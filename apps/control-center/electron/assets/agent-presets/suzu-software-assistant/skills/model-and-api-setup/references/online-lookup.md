# 厂商官网查询

内置厂商参考缺少所需字段，或用户询问当前模型、地域、套餐与接口变化时，查询厂商官网。

## 查询顺序

1. 从当前厂商参考中的官方资料入口读取模型、Base URL、协议与 Key 类型。
2. 已知官方域名时，在该域名内查找对应 API 文档或 `llms.txt`。
3. 未收录厂商先定位其官方开发者平台，再核对域名、API Key 创建入口和接口文档属于同一厂商。
4. 用官网字段组装 `suzu_main_model_save` 或 `suzu_api_connection_save` 的输入。

联网查询使用厂商名称、功能、模型和接口字段作为关键词。API Key 只传给 Suzu 的本机保存工具。

记录适合保存的事实：厂商/套餐、官方 Base URL、协议、模型标识和适用能力。价格、可用模型、地域与套餐限制以当次官网结果为准。
