# 智谱 GLM

## 主模型

- 工具厂商 ID：`zhipu`
- Suzu 地址：`https://open.bigmodel.cn/api/paas/v4`
- Suzu 协议：`openai-completions`
- Suzu 默认模型：`glm-5.2`
- 用户只提供智谱 API Key 且用途是主模型时，可使用默认值保存。

## 独立 API 连接

- 工具厂商 ID：`zhipu`
- 预设地址：`https://open.bigmodel.cn/api/paas/v4`
- 连接类型：`openai-compatible`
- 默认模型按能力选择；模型能力和编码以智谱当前模型目录为准。
