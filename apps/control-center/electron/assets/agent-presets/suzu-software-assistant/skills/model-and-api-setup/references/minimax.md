# MiniMax

## 主模型

- 工具厂商 ID：`minimax`
- Suzu 使用中国区 Anthropic 兼容地址：`https://api.minimaxi.com/anthropic`
- Suzu 默认模型：`MiniMax-M2.7`
- Suzu 已登记模型包含 `MiniMax-M2.7`、`MiniMax-M2.7-highspeed`、`MiniMax-M2.5` 系列和 `MiniMax-M2` 系列。
- 用户只提供 MiniMax API Key 且用途是主模型时，可直接保存；用户明确国际区或其他模型时，根据官方资料填写对应地址和模型。

## 独立 API 连接

MiniMax 的语音、图片和视频接口各自有模型与请求格式。先确认具体能力，再按官方文档选择 `custom-openai`、`tts-api` 或 `generic-api`，并填写该接口要求的地址和模型。

## 官方资料

- 中国区开放平台：https://platform.minimaxi.com/docs
- 国际区开放平台：https://platform.minimax.io/docs
