# 已有联系人与相处设定

每位联系人都有独立的聊天记录、资料、记忆、附件、权限设置和已启用能力。创建新联系人时加载 `contact-creation`；这里处理已经存在的联系人。

联系人设置位于“对话 → 选中联系人 → ··· → 设置”。这里可以修改备注和头像，调整聊天显示与时间显示，并选择审批模式。默认的全权限适合由用户信任的联系人；“工作目录可写”和“只读”适合需要收紧本机操作范围的场景。

## 从萌娘百科查找并设置头像

用户希望从网上为联系人找二次元角色头像时，默认只使用萌娘百科的公开角色检索，不再自行扩大到其他网站：

1. 确认目标联系人和角色名；用户已经给出 `contactId` 时保留该 ID。
2. 调用 `suzu_software_action`：`action` 使用 `lookup-contact-avatar`，`input` 使用 `{ "query": "角色名" }`。该动作只查询萌娘百科，并把公开头像预览保存到软件管理的本机路径。
3. 工具返回 `completed` 时，保留返回的 `title`、`sourceUrl` 和 `avatarPath`。工具返回 `needs-confirmation` 时，给出返回的 2 至 4 个 `title` 与 `sourceUrl` 供用户确认；确认后以 `{ "title": "选定条目名" }` 再次调用 `lookup-contact-avatar`。工具返回 `not-found` 时，说明萌娘百科没有可用预览，并询问用户是否改用本机图片或指定其他来源。
4. 设置前，使用本机可用的图像处理方式另存一张裁后的正方形图片：以人物面部或上半身为中心取正方形区域，保留比例且不拉伸；原图保持不动。人物位置不清楚时，先用可用的图片理解能力确认，仍无法判断则请用户确认裁剪位置或换图。裁后文件仍须为 PNG、JPEG 或 WebP，且不超过 2 MB。
5. 调用 `suzu_software_action`：`action` 使用 `set-contact-avatar`，`input` 使用 `{ "contactId": "联系人 ID", "avatarPath": "裁后图片的绝对路径" }`。只有联系人名称时，先用 `contactName` 代替 `contactId`。
6. 工具返回 `needs-confirmation` 时，把候选 `contactId` 交给用户确认，再用选定 ID 重试；返回 `completed` 后，最终只汇报萌娘百科来源、已裁成正方形和保存结果。

用户提供的是本机图片时，取得它的绝对路径后从第 4 步开始执行。

相处设定位于“关系 → 相处设定”。页面固定提供三份资料：

- `SUZU.md` 是总设定，用来放关系规则、长期互动方式与资料引用。
- `persona.md` 是 Agent 自己的人格、身份、说话方式和行为习惯。
- `user.md` 是用户本人的资料、偏好与希望被如何对待的信息。

也可以添加其他 Markdown 资料；把它作为 `@文件名.md` 单独一行写进 `SUZU.md` 后，保存时软件会把它一并纳入这位联系人的设定上下文。

起草或编辑人设时，把角色的名字与身份、和用户的关系、性格与表达方式、长期习惯和互动边界写进 `persona.md`。用户本人的经历与偏好写进 `user.md`。在人设中，“你”指这位联系人，“用户”指用户；采用第三人称也可以，整份资料保持同一叙述视角。保存后的新一轮聊天会读取新内容。

主动关心与长期记忆的开关也在当前联系人的聊天设置。长期记忆的查看与维护位于“关系 → 记忆”，日记位于“关系 → 查看日记”。

用户明确点名要查看或修改某位联系人的本机资料时，先确认联系人名称；同名联系人时请求用户确认目标，再读取与修改对应资料。
