# 创建可直接聊天的联系人

创建完成时，这位联系人应当已经具备稳定的角色个性、鲜明的表达方式和自然的相处起点。联系人名称、角色设定与相处情境在同一轮准备并保存。

## 资料视角

`personaContent`、`relationshipContent` 和 `userContent` 最终都会成为新联系人 Agent 读取的资料。整套资料使用同一套指代：“你”始终指这位联系人 Agent，“用户”始终指使用 Suzu Lives 的用户，角色名称与“你”指同一个人。`personaContent` 与 `relationshipContent` 默认直接写给联系人本人；`userContent` 使用“用户”描述用户本人。

## 识别角色

- 用户只给出一个能明确识别的角色名称时，把它理解为“按这个角色配好并创建”。公开角色先用 `lookup-contact-avatar` 取得角色资料与头像预览，再在本轮生成 `personaContent` 与 `relationshipContent`。
- 用户给出原创角色或补充要求时，以这些信息为核心补全角色，使其能够进行持续、自然的日常交流。
- 同名角色较多，或作品、时期、版本会明显改变人物时，仍先查找资料；工具返回候选后，用角色名称和关联作品问一个能确定指向的问题。
- 原创名称尚不足以判断角色时，优先确认一个最能决定成品的问题，例如角色身份、与用户的关系或期望的相处气质。

## 角色设定

`personaContent` 写入 `persona.md`，描述角色本人。使用紧凑、直接的 Markdown，让每段内容都能帮助模型判断“这个人此刻会怎么想、怎么回应”。通常组织为：

1. 身份、经历与当前处境中最能定义角色的部分。
2. 核心动机、重视的事、情绪习惯与做决定的方式。
3. 面对亲近、冲突、关心、玩笑、低落等常见情境时的具体反应。
4. 说话节奏、常用措辞、称呼习惯、幽默感和情绪表达方式。
5. 两到四段简短对话示例，覆盖不同情绪，让角色声音可以被直接模仿。

优先写可观察的反应和具有辨识度的语言，让角色特征在对话里自然显现。

公开动漫或游戏角色先调用 `suzu_software_action` 的 `lookup-contact-avatar`，输入 `{ query }`，暂不提供联系人。软件会用 Bangumi 确认角色并同时返回别名、关联作品、属性、简介与本机头像预览；肖像可以来自更适合作为头像的图片源。返回 `needs-confirmation` 时，根据候选名称和作品让用户确认，再以 `{ query, candidateId }` 重试。返回 `completed` 后，使用 `title` 作为建议联系人名称，以 `profile` 中的 Bangumi 资料为事实基础，将身份、性格、动机、反应方式和语言特征转写为可直接用于聊天的人设，并保留返回的 `avatarPath`。

## 相处情境

`relationshipContent` 写入 `SUZU.md`，内容直接写给联系人本人，通常组织为：

1. `# 你与用户的相处`。
2. 用户与你如何认识，以及你们目前已经成立的关系。
3. 你如何称呼用户，用户如何称呼你。
4. 你与用户平时怎样相处，以及当前的亲疏程度。
5. 你此刻正在做什么，这次长期聊天从什么日常情境开始。

用户没有指定关系时，选择符合角色性格、能够立刻自然交谈并留有发展空间的起点。

用户明确提供了自己的经历、偏好或希望被如何称呼时，再整理为 `userContent` 写入 `user.md`。

## 创建与继续完善

调用 `suzu_software_action` 的 `create-contact` 动作，输入 `{ name, personaContent, relationshipContent, userContent? }`。工具返回 `completed` 后，联系人、独立工作区、默认能力、角色设定与相处情境都已经准备好；返回 `partial` 时，根据返回结果继续补齐对应资料。

创建结果中的 `contactId` 是后续操作的稳定标识。继续修改 `SUZU.md`、`persona.md`、`user.md`，或调整联系人备注、置顶、免打扰、长期记忆、审批模式和思考强度时，使用 `suzu_contact_update`。

为公开角色创建联系人后，用创建结果中的 `contactId` 和预览结果中的 `avatarPath` 调用一次 `set-contact-avatar`；角色和图片已经在前一步确定，这一步完成视觉构图、裁剪与保存。用户提供了本机图片时，同样直接把该图片交给 `set-contact-avatar`。原创角色先完成其余资料，让联系人可以立即开始聊天。
