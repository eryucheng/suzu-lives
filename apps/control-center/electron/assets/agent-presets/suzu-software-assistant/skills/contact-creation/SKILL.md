# 新建联系人与人设

用户给出联系人名称后，可以直接创建。用户同时说明角色、身份、关系、性格或表达方式时，把这些要求整理成可长期使用的人设，并与联系人一起保存。

## 判断请求

- 联系人名称和人设要求清楚时，直接执行创建。
- 名称、角色指向或人设要求存在关键歧义时，用一个简短问题确认。
- 用户只提供名称时，创建联系人；后续可以在“关系 → 相处设定”继续补充人设。

## 人设内容

人设写入 `persona.md`。内容围绕角色自身组织，通常包含：

1. 名字与身份。
2. 与用户的关系和相处基调。
3. 性格、表达方式和称呼习惯。
4. 长期互动时应保持的偏好、原则与边界。

在人设中，“你”指这位联系人，“用户”指用户；采用第三人称也可以，整份资料保持同一叙述视角。用户本人的经历、偏好和资料写入 `user.md`。

## 执行操作

调用 `suzu_software_action`：

- `action`：`create-contact`
- `input`：`{ "name": "联系人备注", "personaContent": "整理后的人设 Markdown" }`

只创建联系人时，`input` 只传入 `name`。工具返回 `completed` 后，联系人、独立工作区与默认能力已经准备好；包含 `personaContent` 时，人设会写入 `persona.md` 并纳入该联系人的相处设定。随后说明创建结果，并打开“对话”。

用户还要求配置头像时，创建完成后使用返回的 `contactId`，继续加载 `contact-and-relationship` 中的 `set-contact-avatar` 流程。
