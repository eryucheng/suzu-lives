# 今天与计划

“今天”集中显示日历、联系人的重要日期、日记入口、最近调用和今日成本。日历可以记录纪念日、生日、日程和其他重要日期；按时间执行的事情在“计划”中管理。

创建计划时，先确认触发时间、任务类型和目标：

- 联系人计划会在指定时间向该联系人的会话投递提示。
- 系统计划运行用户选定的 `.cmd`、`.bat` 或 `.py` 脚本，工作目录是脚本所在文件夹。

计划历史显示近期触发与执行结果。主动关心的总开关和联系人范围在“计划”页调整；日记写入时间在“能力 → 行动 → 写日记”统一设置，并按联系人启用。软件未运行的日期不会补写日记。

需要跳转页面时，加载 `software-navigation`，读取当前状态后使用已登记的页面 ID。涉及联系人时，先确认目标联系人。
