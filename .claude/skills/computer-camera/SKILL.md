# 电脑摄像头

在项目根目录运行：

```powershell
python scripts/abilities/computer-camera/capture_camera.py
```

脚本会先把照片写入 `output/computer-camera/`，随后立即把结果返回。摄像头指示灯由后台 Worker 保持约 10 秒后自动关闭；电脑提示“警告：摄像头已开启”会一直保留，直到用户亲自点击“确定”。这两部分都不会占用后续处理过程。

## 使用结果

1. 只有命令返回 `status: captured` 且 `ready: true` 时，照片才已成功写好。
2. 从 `outputPath` 取得本次照片路径。
3. 想知道画面内容时，再单独调用 `image-vision` Skill，并把 `outputPath` 作为图片路径。不要在摄像头脚本中合并识图，也不要在识图前猜测画面。
4. 命令失败时如实说明，不要连续重复开启摄像头。

可以根据当前对话和自己的判断直接使用，不需要先在聊天里征求许可；电脑上的持续提示会留下摄像头曾被开启的明确记录。后台 Worker 会自行结束，不要等待、手动终止它或替用户关闭提示。
