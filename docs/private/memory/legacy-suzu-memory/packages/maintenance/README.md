# @suzu-memory/maintenance

长期记忆整理协调器。它把维护工作按计算性质分开，但复用各领域已有的权威队列与处理器。

- 零模型即时任务：新长期节点落库后同步明确关系、关联图和巩固计划，并登记后续任务。
- Embedding 批任务：只领取新增或检索表达变化节点；内容哈希相同的向量直接复用。
- LLM 语义批任务：按检索上下文、结构提案、状态分析和回顾性巩固分别处理，提示词与 Schema 不混用。
- 高层闭环：只自动接受本轮产生、证据边界完整的本人明确 `reported` 状态新建或补强；接受后登记检索背景与 Embedding，不递归提出新结构。

本包不内置 Cron，不扫描旧数据库，也不把模型失败回滚成原始证据丢失。Worker 或宿主通过有界执行入口显式 flush。

人物状态的进一步分析与其他语义任务采用相同失败原则：基础事件和证据先保留；技术失败最多自动尝试三次；耗尽后把现有候选及三次错误记录转入统一人工审核，并继续后续任务。人工审核直接接受或驳回候选，不把人工动作解释成一次模型重试。

结构、关系、状态变化、冲突、行为推断和来源不完整的提案一律保持 `pending`，由 Service 的统一审阅接口处理。维护包不替人决定这些语义结论。
