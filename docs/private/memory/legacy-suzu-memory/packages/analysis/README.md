# @suzu-memory/analysis

Suzu Memory 的结构化状态分析包。

它负责把长期提取和结构化阶段产生的待分析请求，进一步整理为人物身份、偏好、目标、观念、能力、自我理解、关系、习惯、状态和情感关联等可审阅提案。

这个包属于正式运行链路，不包含检索评测数据集、奖励归因、强化学习、参数校准或公开基准测试。那些研发能力保留在 @suzu-memory/evaluation，不会成为基础版 Agent 的运行依赖。

系统内置生成器会把同一状态族、同一证据阶段的专职分析组合成一次结构化调用，但每个专职维度仍保留独立 Schema、解析器、证据门禁、运行记录和弃权结果。与既有当前状态的比较属于第二阶段；快照没有当前状态时，`no_current_state` 由本地确定性规则生成，不为已知答案调用模型。不声明组合能力的自定义生成器继续沿用逐专职调用契约。
