# 长期素材库

`assets` 保存需要长期保留、会被 Agent 的能力反复使用，但不属于代码、聊天记忆或生成结果的素材。

## 当前分类

- `visual-references/`：人物、地点、房间、物品和穿搭的视觉参考图，以及描述这些图片的 `manifest.json`。

## 以后可以加入

- `voice-references/`：定型声线、克隆音色或语音风格需要的长期音频样本；
- `avatar-references/`：头像、立绘、Live2D 或 3D 形象等长期角色素材；
- `audio-references/`：固定环境声、提示音或其他需要反复使用的声音素材。

只在真正出现相应素材时创建子目录，不预先制造空文件夹。

## 不放在这里的内容

- 聊天、事件和长期记忆放在 `memory/`；
- 脚本及其局部配置放在 `scripts/`；
- 人工使用的工具放在 `tools/`；
- 每次生成的图片、音频和中间结果放在 `output/`；
- API Key、令牌和账号凭证继续放在各功能自己的本地配置中。

私人脸部、住宅和声音素材不应提交到公开仓库。
