# Media understanding

This package owns safe plans plus gated OpenAI-compatible executors for image vision and video understanding. Its workers are invoked through Suzu's host-neutral internal capability CLI; Agent-specific Skill/MCP adapters do not call workers directly.

The canonical image command is `suzu-lives capability image-vision analyze --input-json '<JSON>'`, where input contains `path`, optional `question`, optional software-data-root-scoped `configPath`, and optional `noRetry`. Its configuration must be under `<dataRoot>/capabilities/image-vision/`; use `resources/image-vision.config.example.json` as the public schema reference. The bundled worker preserves Pillow-based EXIF transpose, bounded JPEG conversion, OpenAI-compatible request construction, neutral retry behavior, and refusal boundaries. Temporary conversion files stay under the same software data root, and successful provider usage is appended through `@suzu-lives/cost-ledger` to the host-supplied Agent ledger.

The canonical video command is `suzu-lives capability video-understanding analyze --input-json '<JSON>'`, where input contains `source`, optional `question`, `cacheKey`, `configPath`, `noCache`, `keepClip`, and `dryRun`. Its configuration must be under `<dataRoot>/capabilities/video-understanding/`; use `resources/video-understanding.config.example.json` as the public schema reference. The bundled worker preserves FFmpeg/FFprobe verification, three-stage MP4 compression, the Base64 size boundary, content SHA plus question/cache-key caching, OpenAI-compatible `video_url` streaming/non-streaming response handling, stable JSON errors, and usage events in the host-supplied Agent ledger. Work directories, cache entries, and retained clips stay below the same software data root; `dryRun` prepares and validates without requiring a key or contacting a provider.

The gated image/video executors remain separate: they read only their Suzu Lives configuration and require the registry gate, a private verified authorization context, concrete local-tool checks, and a software-provided safe credential resolver. The standard capability CLI routes are the stable execution paths for explicit Agent Skills. Tests use temporary data roots, fake commands, and local fake HTTP only.
