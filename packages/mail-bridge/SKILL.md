# Mail Bridge

邮箱通道只负责收发邮件，不拥有收件方的设备或自动化语义。通过软件内的 `suzu-mail-bridge` Skill 使用时，先读取与当前任务匹配的邮件业务 Skill；它会说明什么时候发信以及使用什么主题。随后再读取 `suzu-mail-bridge`，按它提供的方式发送邮件。

稳定软件入口：

`suzu-lives mail-bridge send '主题' '正文'`

这个命令是底层收发入口；软件内的 Agent 使用邮件业务 Skill 指定的主题。

`已发送` 只表示请求邮件交给邮箱服务器，不代表收件方已经处理。发送后等待正在运行的 Suzu 邮件反馈接收器；不要重复发送、不要编造外部结果。收到图片路径后，使用现有图像理解能力。

反馈监听由 Suzu 软件启动，并直接排入能力设置中勾选的一个或多个会话。不要从聊天 Agent 的终端执行或停止监听；命令行只可预览主题映射：

`suzu-lives mail-bridge receive --preview '<主题>' '<内容>'`

软件代码、配置、反馈状态和附件目录都在 Suzu Lives 统一软件数据根；运行时不会使用远程转发，也不会把私密内容展示到界面。
